# OpenMAIC v0.2 需求文档

## 1. 版本范围

`v0.2` 包含两项核心能力：

1. 课程导入导出功能
2. 生成课件后支持人工介入修改

本版本不包含：

1. 多人实时协作编辑
2. 跨实例知识库同步
3. 权限审批工作流

## 2. 背景

`v0.1` 已完成：

1. 课程生成链路
2. 课堂持久化
3. 知识库、记忆、知识库视频接入
4. PPT 与资源包导出

但当前仍缺两块关键产品能力：

1. 课程结果无法以“完整可迁移包”的形式导入导出
2. 生成结果虽然可继续生成和导出，但缺少正式的人为编辑闭环

## 3. 需求目标

### 3.1 课程导入导出

系统需要支持：

1. 将单个课程导出为标准课程包
2. 将课程包重新导入到当前实例
3. 导出的课程包包含结构数据和所需资源文件
4. 导入时支持版本校验、冲突处理和错误反馈
5. 导入后的课程可继续编辑、播放、导出 PPT

### 3.2 人工介入修改

系统需要支持：

1. 用户对生成后的课程元信息进行修改
2. 用户以“直接编辑”的方式修改现有课件
3. 用户以“对话提示词”的方式重新制作现有课件
4. 用户对页面顺序、标题、讲稿、上下文摘要进行调整
5. 自动保存草稿
6. 查看历史版本并恢复

## 4. 功能需求

### 4.1 课程导出

系统必须支持：

1. 从课堂页导出课程包
2. 从课程列表导出课程包
3. 导出文件格式使用单文件压缩包
4. 导出内容至少包含：
   - 课程元信息
   - 页面结构
   - 行为脚本
   - 讲稿
   - 上下文信息
   - 媒体资源
   - 知识库资产引用清单
5. 支持导出模式：
   - 仅结构
   - 结构 + 资源

### 4.2 课程导入

系统必须支持：

1. 上传课程包进行导入
2. 校验课程包版本、格式和文件完整性
3. 选择导入策略：
   - 直接新建课程
   - 作为现有课程副本导入
4. 导入完成后返回新课程 `id`
5. 导入失败时返回具体错误原因

### 4.3 人工修改

系统必须支持：

1. 修改课程标题、描述、语言、风格
2. 修改场景标题、顺序、类型元信息
3. 支持直接编辑 slide 内容中的文本、图片、视频、形状等元素
4. 支持直接编辑 quiz / interactive / pbl 页面内容
5. 支持直接编辑页面动作列表、讲稿与页面级上下文备注
6. 支持删除页面、复制页面、插入新页面
7. 支持在对话窗口输入提示词，对整课、单页或局部内容重新制作
8. 支持选择“保留人工修改部分”或“覆盖指定部分”后再生成
9. 自动保存和手动保存

### 4.4 对话重制

系统必须支持：

1. 在课堂页提供独立对话窗口或侧边面板
2. 用户输入自然语言提示词描述修改意图
3. 支持重制范围：
   - 整门课程
   - 单个页面
   - 当前页面内指定元素
4. 支持重制模式：
   - 仅改文案
   - 改布局
   - 改媒体
   - 全量重制
5. 重制前展示影响范围和覆盖策略
6. 重制后生成草稿结果，允许人工确认后应用
### 4.5 历史版本

系统必须支持：

1. 保存课程级版本快照
2. 展示版本列表
3. 查看版本摘要
4. 将课程恢复到某一历史版本

## 5. 非功能需求

### 5.1 兼容性

1. 课程包导入导出需要显式声明格式版本
2. `v0.2` 导出包必须能被后续版本兼容处理
3. `v0.1` 现有课堂数据不应因 `v0.2` 发布而失效

### 5.2 可恢复性

1. 自动保存失败不能导致当前编辑内容直接丢失
2. 导入过程必须先校验后落盘
3. 导入中断不能污染现有课程

### 5.3 可观测性

1. 导入导出必须有任务状态
2. 人工编辑必须能看到最近保存时间
3. 历史版本必须记录来源和时间

## 6. 验收标准

### 6.1 课程导入导出

满足以下条件视为通过：

1. 任意一门本地课程可导出为标准课程包
2. 课程包可在同一实例重新导入
3. 导入后课程页面数、页面类型、核心媒体资源与原课程一致
4. 导入后仍可继续编辑、播放和导出 PPT
5. 对损坏压缩包、缺少 `manifest`、版本不兼容等情况有明确错误提示

### 6.2 人工编辑

满足以下条件视为通过：

1. 用户可通过直接编辑修改课程和页面元信息并保存
2. 用户可修改 slide 元素并立即在课堂页看到结果
3. 用户可通过对话提示词触发单页或整课重制
4. 重制结果不会直接覆盖当前成品，而是先进入草稿或确认态
5. 用户刷新页面后编辑结果仍在
6. 用户至少可以恢复到一个历史版本

## 7. 实施优先级

### P0

1. 课程包格式定义
2. 导出任务与导入任务链路
3. 课程草稿保存与恢复
4. 直接编辑保存链路
5. 对话重制链路
6. 课程版本快照

### P1

1. 课程列表导入导出入口
2. 课堂页编辑入口
3. 课堂页对话重制入口
4. 冲突处理与导入前预检

### P2

1. 增量导出
2. 细粒度版本差异展示
3. 协作编辑预留结构
