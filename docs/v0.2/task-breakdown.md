# OpenMAIC v0.2 开发任务拆解

## 1. 目标

把 `v0.2` 拆成可执行阶段，确保开发顺序、依赖关系和验收边界清楚。

## 2. 阶段划分

### P0 课程导入导出骨架

目标：

- 先打通课程包格式和后台任务主链路

任务：

1. 定义课程包目录结构和 `manifest.json`
2. 增加导出任务存储与状态查询
3. 增加导入任务存储与状态查询
4. 实现课堂 JSON + `context.json` 的基础打包
5. 实现 ZIP 上传、解压、manifest 校验
6. 实现导入后创建新 classroom

验收：

- 一门现有课程可导出为课程包
- 课程包可重新导入并生成新课堂

### P1 资源级导入导出

目标：

- 让课程包不仅有结构数据，还包含实际媒体资源

任务：

1. 收集课程引用图片、视频、音频、poster
2. 写入 `assets/` 和资源索引
3. 导入时重写资源路径
4. 补导入导出完整性校验

验收：

- 导出后再导入，媒体资源可用
- 导入后的课程可继续导出 PPT 和资源包

### P2 直接编辑

目标：

- 支持正式的人工直接编辑与保存

任务：

1. 课堂页增加 `Edit Mode`
2. 增加 `PATCH /api/classroom/:id`
3. 增加本地草稿模型
4. 增加保存状态展示
5. 增加离开页面未保存提示

验收：

- 用户可修改课程和页面内容并保存
- 刷新页面后仍能恢复最新草稿或已保存结果

### P3 版本快照

目标：

- 让直接编辑和后续重制都可回滚

任务：

1. 增加 revision 存储模型
2. 增加快照创建接口
3. 增加快照列表接口
4. 增加快照恢复接口
5. 在关键操作前自动创建快照

验收：

- 修改前可创建快照
- 可从历史快照恢复课程

### P4 提示词重制

目标：

- 支持通过对话窗口对整课、单页或局部内容重新制作

任务：

1. 增加 `regenerate` 任务模型
2. 增加任务创建、查询、应用、丢弃接口
3. 增加课堂页 `Rework with Prompt` 面板
4. 支持选择范围和模式
5. 支持保留人工修改或覆盖指定部分
6. 结果先进入预览态，不直接覆盖课程

验收：

- 用户可发起重制任务
- 用户可查看预览并决定应用或丢弃

### P5 收口与发布

目标：

- 完成测试、回归、部署验证

任务：

1. 补齐服务层单元测试
2. 补齐路由级集成测试
3. 补齐关键 E2E
4. 执行 `tsc`、`eslint`、`vitest`
5. 执行 `docker compose build`
6. 完成人工验收

验收：

- 自动化测试通过
- Docker 构建通过
- 关键业务链路人工验证通过

## 3. 并行关系

可并行：

- `P0` 的课程包格式定义和导入导出任务存储
- `P2` 的前端编辑模式和 `PATCH` 接口设计
- `P3` 的快照模型和快照路由设计

强依赖：

- `P1` 依赖 `P0`
- `P4` 依赖 `P2` 和 `P3`
- `P5` 依赖前面所有阶段

## 4. 建议开发顺序

建议顺序：

1. `P0`
2. `P1`
3. `P2`
4. `P3`
5. `P4`
6. `P5`

原因：

- 课程导入导出是结构基础
- 直接编辑和快照是人工介入的底盘
- 提示词重制必须建立在“可保存、可回退”的前提上

## 5. 每阶段完成定义

每阶段完成前，至少满足：

1. 对应文档更新
2. 关键接口或页面已经落地
3. 有最小自动化测试
4. `tsc` 通过
5. `eslint` 通过

## 6. 建议分支切分

建议按功能拆分子分支：

1. `feature/course-package-export-import`
2. `feature/classroom-direct-editing`
3. `feature/classroom-revisions`
4. `feature/classroom-prompt-regeneration`
5. `feature/v0.2-release-hardening`

统一合回：

- `dev/v0.2-course-import-editing`
